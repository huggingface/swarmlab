# Dogfood: a fresh agent runs an experiment from the docs alone (2026-10-07)

Task given: "does telling Haiku agents that a shared board exists change how fast a swarm reaches consensus on the Flag Game?" N=6, 5 rounds, two arms, one seed, $1.00 total cap. The agent saw only README, AGENTS.md, skill/SKILL.md and `--help`.

Outcome: completed end to end in 6.5 min wall time, $0.963 spent, repo untouched. Default arm reached full consensus in round 2; board-mention arm in round 3 (one agent posted a wrong crop reading). Default agents read the board (read rate 0.67) but never posted; with the sentence they posted 0.7 per agent-round. Note: the default prompt already lists `read_board`/`post` in its tool list, so the arm tests a nudge, not awareness.
