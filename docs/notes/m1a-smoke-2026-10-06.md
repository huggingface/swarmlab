# M1a smoke run (2026-10-06)

First end-to-end run of the merged WP1–WP4 code: FlagGame text variant, 16 scripted agents, 8 rounds, seed 3, phase-commit. Metrics are per round.

| condition | belief.accuracy by round | comm.read_rate |
|---|---|---|
| Silent × 16, broadcast | 0.69 flat | 0 |
| EvidenceAggregator × 16, broadcast | 0.69, then 1.0 from round 2 | 1.0 |
| EvidenceAggregator × 16, gossip k=1 | 0.69, 0.81, 0.81, 0.75, 0.88, 0.69, 0.81, 0.75 | 1.0 |
| EvidenceAggregator × 16, broadcast + DelayPolicy(2) | 0.69 until round 3, 1.0 from round 4 | 1.0 |

Observations:
- "Available next round" holds: round-1 posts move accuracy in round 2 under broadcast, and in round 4 under a 2-round delay (1 + 1 + 2).
- Gossip with no relaying does not converge: agents post their crop once in round 1, so under k=1 each agent ever sees one peer crop. The oscillation is `EvidenceAggregator` re-breaking ties randomly each round. A relaying participant (re-post what you heard) is the obvious first experiment once LLM agents exist, and a "keep previous guess on tie" variant would remove the noise.
- `comm.hops` is 1.0 everywhere because nothing is relayed; it will only exceed 1 once agents forward content.
- Run directory for 16 agents × 8 rounds: 1,642 events, snapshots every round, no issues with sizes.
- Re-running an experiment with the same name and seed into the same `out` refuses to overwrite (`FileExistsError`), by design.
