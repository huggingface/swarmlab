Reading:
- The registry doubled coverage even though the agents mostly ignored acquire outcomes: a failed acquire tells an agent the cell is taken, which steers it elsewhere. Advisory measured 2,199 violations; enforced turned the same behaviour into 0 overwrites and 38 wasted paints instead of 267. That is the claim-policy primitive doing exactly what the design intended: advisory measures, enforced prevents, same agents.
- The dominant harness artefact was the silent paint limit: agents spun on `paint` until the call cap in 75–98% of turns. Fixed in `b0d681c` (immediate refusal, limit stated in the description, `paints_left_this_round` in status, `max_calls: 4` in the spec). The three arms should be rerun on the fixed code before any conclusion about allocation.
- 9B paints the wrong colour 19–61 times per run with only four colours; the target grid is in every observation. Expect this to shrink with a stronger model.
