## 1. Real flags, paper-faithful (`experiments/m6_flag_paper.yaml`, Gemma 4 26B-A4B via HF router → DeepInfra)

### Pilot, seed 1 only (17:37–17:56 UTC, nine runs, $0.35 total)
Hidden flag was **Peru** in every arm (one seed → one flag; the paper draws a country per trial). Accuracy was 0 in eight arms and 0.10 in pairwise-128. Every agent answered Indonesia, Poland or Austria (red-and-white horizontal flags); nobody answered Peru (the only red-and-white vertical flag in the list). So the model reads the crop's colours and uses flag knowledge, but does not use stripe orientation; with Peru as the target the task is nearly unwinnable for it. The manager arms were additionally broken by a harness bug: members answered `{"answer": ...}` instead of `{"country": ...}` and the report parser rejected 146 of their replies, so the manager received nothing (fixed in `d6dfe3a`: the parser now accepts answer-key synonyms). Those three runs are kept under `runs/m6paper/_seed1_manager_prefix/`.

## 3. Framework notes from the night
- A one-seed grid is a one-flag grid: `seeds` must cover several flags in this world. Consider a `FlagGame(flag_per_arm_seed=...)` or documenting that the hidden flag derives from the seed.
- Report-JSON key drift (`answer`/`guess`) silently zeroed a protocol arm; fixed, and the health section now shows it (`report_json:failed` notes).
- The experiment-level cap counts in-flight reservations; with `--parallel`, the last large arms can be refused even when actual spend is far below the cap. Either lower the per-arm hard caps or run large arms first.
