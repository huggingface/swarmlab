## Using it

```python
from swarmlab import Board, Experiment
from swarmlab.medium.topology import Tree
from swarmlab.participants import LLMAgent
from swarmlab.roles import COORDINATOR, assign
from swarmlab.worlds import FlagGame

parts = [assign(LLMAgent(model="fake:reader"), "coordinator" if i % 6 == 0 else "worker")
         for i in range(18)]
exp = Experiment(name="h", world=FlagGame(), participants=parts,
                 medium=Board(topology=Tree(groups=3)),
                 roles={"coordinator": COORDINATOR})  # may_act=True here is the ablation
```

YAML: `roles: {coordinator: {may_act: true}}` (field override of the built-in) and
`participants: [{type: llm, role: coordinator, params: {...}}]`.

## Decisions where the contract was silent

- **Assignment is explicit** (`assign` / YAML `role`), stored on the participant as a private
  attribute, so participant specs do not change. `LLMAgent(role=...)` stays the prompt word it
  was; `apply_role` sets it to the role's name. (The contract says `ParticipantGroup.role` was
  "already a string field"; it was not, it is added here.)
- **Name resolution**: declared roles first, then built-ins by name (written into the spec);
  anything else is an error. A YAML role mapping whose name is a built-in field-merges over it
  (experiment level, then arm level).
- **Spec**: `RunSpec.roles` holds full resolved `Role` dumps (so built-in prompt text is hashed)
  and `participant_roles` one name or None per agent; both are dropped from the serialised spec
  while empty, so runs without roles keep their hash, run.json and spec.yaml byte-for-byte.
- **`budget.max_calls`** replaces the executor's `max_calls_per_turn` for that agent (going over
  ends the turn as `cap`); **`max_tokens`** sets `LLMAgent.max_tokens`. No other keys.
- **`post_fields`**: enforced key/value allowlist on `fields`, advertised as an optional typed
  `fields` object on the `post` schema (strict-compatible). Without it, `fields` behaves as before.
- **`may_act=False`** blocks world action tools only; status tools stay. `registry="read"` keeps
  `registry_get`. Disallowed tools are also hidden from the schemas; `read_board`/`post` vanish
  when the role has no readable/writable channel.
- **`read_board()` without channel** under a role returns only readable channels' items (limit
  after filtering) and leaves the others unread; push delivery uses the same filter.
- **`prompt_append`** is appended to the end of the rendered template (after the tool list,
  before the JSON-protocol section) so it works with custom templates too.
- **Tree**: `groups` int = number of contiguous groups by agent index (top excluded; sizes differ
  by at most one); a post on a non-tree channel (e.g. `main`) goes to the author's default
  channel; the layout comes from the full agent list at bind, so killed agents never reshuffle
  groups. The board gets the Tree's channels at bind (not in `MediumSpec.channels`). Agents
  without a role under a Tree get an anonymous permission set (channels only); their
  `turn_started.role` is None.
- **Forks**: permissions and `prompt_append` come from the child's spec; a participant restored
  from the parent snapshot keeps its restored `model`, `max_tokens`, `system_prompt` and its
  already-rendered system prompt (the existing restore-by-spec rule).

## Known gaps

- `Experiment.estimate` prices participants by their own model, not a role's override.
- `reconfigure` interventions do not change roles (M3c says not required).
- `swarmlab` does not re-export `Role`/`Tree` at top level (import from `swarmlab.roles` and
  `swarmlab.medium.topology`), to keep `__init__.py` out of this branch.
