## Using it

```python
from swarmlab.interventions import DelayDelivery, InjectPost, Intervention, KillAgents

exp = Experiment(..., interventions=[
    DelayDelivery(agents=["a000"], rounds=2, at_round=3),
    InjectPost(text="the flag is not B", when={"metric": "belief.consensus", "op": ">=", "value": 0.9}),
    KillAgents(agents=3, at_round=5),                       # 3 random live agents (ctx.rng)
    KillAgents(agents=["a001"], mode="revive", at_round=8, name="revive"),
])

class SetTruth(Intervention):                               # custom: subclass and call ctx.ops
    def __init__(self, candidate: str, **trigger):
        super().__init__(**trigger)
        self.candidate = candidate
    def apply(self, ctx):
        ctx.ops.world("set_truth", name=self.candidate)
```

```yaml
interventions:                     # experiment level, applies to every arm
  - {type: inject_post, params: {text: hello, at_round: 2}}
arms:
  muted:
    interventions:
      - {type: mute, params: {agents: [a000], rounds: 2, at_round: 1}}
```

Built-in params: `inject_post(text, author="system", channel="main", fields=None, recipients=None)`,
`delay_delivery(agents, rounds, duration=None)`, `mute(agents, rounds)`,
`kill_agents(agents, mode="kill"|"revive")`, `patch_private(agent, data)`,
`reconfigure(agents, settings)`. Each also takes one trigger (`at_round`, `every`+`start`,
`when`, `on_event`) and an optional `name`. `agents` may be an int (k random live agents) for
`delay_delivery`, `mute`, and `kill_agents` in kill mode.

## Decisions where the contract was silent

- **Metric values for `when`.** Triggers run before probes and metrics, so `ctx.metrics` is a
  lazy fold of deep copies of the run's metrics over this round's logical events so far. This
  round's commit counts and this round's probes do not, so a probe-sourced metric lags one round.
- **Events.** There is one event per agent for delay, mute, kill, revive, patch_private and
  reconfigure (`agent` = that agent, `affected=[agent]`). inject_post, set_policies,
  set_topology and world write one event with `affected=[]`. `params` holds the operation's
  arguments. Hook exceptions of any kind (and board `ValueError`s such as an unknown channel or
  policy) give `ok=False` with `error` (`"not supported: ..."` for `NotSupported`, else
  `"<ExcType>: ..."`), and the run continues. An exception raised in `apply` outside `ops`
  propagates, so the round is lost and the run is resumable.
- **inject_post fan-out.** An author that is a run agent goes through the topology over the
  live agents. Any other author (`"system"`) reaches every live agent, because topologies such
  as gossip or groups cannot place a non-agent. `recipients` limits the fan-out to those live
  agents and bypasses the topology. The `post` and `delivery` events are logged before the
  `intervention` event, in round r. `round_committed.n_posts` and `n_deliveries` still count
  only the turns' posts.
- **delay.** `delay(agents, rounds, *, duration=None)`: `duration` limits it to commits through
  `round + duration`. None means until cleared, and `rounds=0` clears. Setting a delay replaces
  the agent's previous one. In immediate mode the delay counts from `round + 1`, like
  `DelayPolicy`, so a000 still gets eligible round 6.
- **mute.** Withholds posts committed through `round + rounds`. Posts of the firing round were
  already committed, except injected ones. Mutes only extend.
- **kill / revive.** `runner.live_agents` changes at once, so killed agents are skipped by this
  round's probes. Metrics get the new live list at the next round start, which is what replay
  reconstructs from `round_started.order`. `revive` restores agent order. Unknown agents give
  `ok=False`.
- **set_policies / set_topology** are recorded in the board snapshot and win over the
  constructor config on restore. This includes a fork under an edited medium.
- **World ops in replay.** `patch_private` and `world` events (`ok`) are re-applied to replay's
  private world copy from `params`, and the truth is re-sent to metrics. Replay never calls
  intervention plugins.
- **FlagGame.** The changed-crop line comes after the crop rows, behind a blank line, so the fake
  provider's listing parser and `parse_observation` both keep working. `observe` clears the
  flag (a crash mid-round restores it from the snapshot). `set_truth` swaps truth and rival
  when the new truth is the rival, and otherwise leaves the rival alone. `World.intervene`
  takes `name` positional-only, because `set_truth` itself takes a `name=` kwarg; the same
  applies to `Ops.world`.
- **reconfigure persistence.** `LLMAgent` settings are plain attributes in its `Persistable`
  snapshot, so a reconfiguration survives resume and fork. `params` and the spec hash stay
  unchanged. `system_prompt` resets the rendered system message, which is re-rendered at the
  next turn.
- **Spec.** `Intervention.spec()` flattens `**trigger` into `params` and drops trigger kwargs
  left at their defaults. Names default to the entry point (built-ins) or the class name and
  must be unique per run (`name=` to disambiguate). An intervention is restored on fork when
  its spec is in the parent's list, which is the same rule as metrics.
