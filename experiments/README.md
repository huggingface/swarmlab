# Experiments

- `m2_flaggame.yaml` — M2 Flag Game proving experiment, phase 1 (N=16, 10 rounds, 3 seeds): broadcast vs gossip(k=1), phase-commit vs sequential (`-seq` arms), Haiku 4.5 vs Qwen3.5-9B. Probes every round. Phase 2 (N=64) and the paired-run influence measurement follow once phase 1 has validated the pipeline.

Cost model (from the 2026-10-06 smoke, full-history memory): a Haiku agent-round costs about $0.009 in round 1 and grows roughly $0.004 per round as context accumulates; broadcast at N=16 adds about 16 posts per read. Expected per run: Haiku broadcast about $8 (probes are a third of it, since a probe re-sends the agent's full context), Haiku gossip about $5, Qwen about $0.6. The framework's `swarmlab estimate` is a flat worst case (20 calls per turn × 3,000 prompt tokens) and does not model growth; treat it as a ceiling check, not a forecast.
- `m5_flag_image.yaml` — M5 Flag Game image modality (not launched; needs approval): Haiku 4.5 at N=8, 8 rounds, seeds 1-3, broadcast, belief probe every round; `image-haiku` (candidates and crops as PNG images) vs `text-haiku` (colour-letter grids), same worlds per seed. `swarmlab estimate experiments/m5_flag_image.yaml --calls-per-turn 6 --prompt-growth 730` gives a worst case of $3.16 per run, $19.0 for the 6 runs (the M2 note: the worst case overstated Haiku about 4x). Smoke first with `tools/real_smoke.py --arms haiku-image` and `swarmlab preflight ... --arm image-haiku`.
- `m2_vllm_qwen9b.yaml` — M2 Flag Game on a self-hosted Qwen3.5-9B: vLLM inside an HF Job next to the runner (docs/handoff/WP8.md). Arms `bc-qwen9b-16`, `gossip-qwen9b-16`, `bc-qwen9b-64`, 10 rounds, seed 1, belief probe every round, belief metrics from world guesses and from the probe. Budget zero: tokens cost nothing per call; the cost is GPU time (a100-large, ~1 h estimated for the three runs). Launch with `swarmlab job run experiments/m2_vllm_qwen9b.yaml --model Qwen/Qwen3.5-9B` (prints only; `--launch` submits).
- `m6_flag_vlm.yaml` — the Flag Game paper's three protocols (not launched; needs approval): `bc-N` (broadcast), `gossip-N` (gossip k=1), `manager-N` (a000 blind, `manager` role, `star` topology; N counts the manager) for N = 4, 16, 128; `hf:google/gemma-4-26B-A4B-it:deepinfra`, image mode, `max_tokens: 1024, max_calls: 5`, window memory of 3 rounds (the `x-memory` anchor; switch to `{memory: full}` and raise the budgets), 10 rounds, seed 1, belief probe every round, belief metrics from guesses and from the probe, `comm.read_rate`, `comm.post_rate`. `collective_status` is off in every arm (it would leak swarm-wide guess counts past the topology). Hard ceilings $0.30 / $1.20 / $16 per run at N = 4 / 16 / 128 (2x the window-memory estimates), soft 0, `total_usd` 30: if the estimates hold, the third N=128 run is refused by the total cap ($18.25 spent + $16 > $30); run it separately or raise `total_usd` to 35. `swarmlab estimate ... --calls-per-turn 5` (flat, no image tokens) gives $8.31 for all nine. Smoke first with `tools/real_smoke.py --arms gemma-image,gemma-manager`.
- `m6_flag_paper.yaml` — faithful replication of the Flag Game paper (not launched; needs approval): the 28 real flags on a 24x16 canvas, 6x4 image crops, name-only candidates, JSON answers (`report_json`), received-message memory H=8, `hf:google/gemma-4-26B-A4B-it:deepinfra` at temperature 0.2 (price pinned in `providers:`). Arms `pairwise-N` (OneSpeaker + gossip k=1 + immediate, 10N rounds, probe every N rounds, stop after 5 consecutive 100%-consensus probes; max_tokens 200), `broadcast-N` (10 rounds, each agent sees the other N-1 current answers, probe every round; 250) and `manager-N` (N observers + blind manager a000 on a star, 10 rounds, no probes; 250) for N = 4, 16, 128, seed 1. `swarmlab estimate` (flat 3,000-token worst case, 2 calls per turn): $3.71 for all nine; hard ceilings sum to $6.75 under `total_usd: 10`. Realistic: broadcast-128 about $1.2 (its prompt carries 127 reports, ~6.5k tokens), everything else well under the estimate. The N=4 arms are the smoke (each under $0.05).
